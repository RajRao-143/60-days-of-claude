# Day 18 — Brain Dump Action Planner

## Overview

For Day 18 of the #60DayClaudeChallenge, I built a reusable Claude Custom Skill called **Brain Dump Action Planner**.

The purpose of this skill is to transform messy notes, meeting transcripts, brainstorming sessions, voice memos, and project discussions into structured and actionable information.

It organizes unstructured content into:

* Summary
* Key Takeaways
* Action Items
* Open Questions
* Risks & Blockers
* Conflicts
* Additional Notes
* Speaker-wise information for transcript analysis

The skill preserves the information provided in the source and does not invent missing details.

---

## Skill Details

**Skill Name:** `brain-dump-action-planner`

**Goal:**
Convert unstructured thoughts and discussions into clear summaries, decisions, questions, risks, and task lists.

A key rule is that whenever information is missing, the skill displays **"Not specified"** instead of making assumptions.
