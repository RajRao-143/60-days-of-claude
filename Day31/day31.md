# Day 31 — AI Supply Chain Control Tower 🚚📦

## 📌 Overview

For Day 31 of the **60 Days Claude Challenge**, I built an interactive AI Supply Chain Control Tower game using Claude.

The project simulates real-world supply chain disruptions and challenges players to make quick operational decisions while balancing service levels, customer satisfaction, inventory health, transportation efficiency, operating costs, and protected revenue.

## ✨ Key Features

- **Live KPI Dashboard:** Tracks service level, customer satisfaction, inventory health, transportation efficiency, operating cost, revenue protected, and performance score.
- **Dynamic Supply Chain Alerts:** Simulates port congestion, supplier delays, truck breakdowns, stockouts, customs issues, demand spikes, factory failures, weather disruptions, inventory discrepancies, and damaged shipments.
- **Decision-Based Gameplay:** Every operational decision has consequences for KPIs, costs, and business performance.
- **Three-Minute Challenge:** A countdown timer creates time pressure, while alert frequency increases throughout the round.
- **Live Event Log:** Records incidents, decisions, resolutions, and KPI changes.
- **Final Performance Report:** Calculates the final score, grade, resolved and missed alerts, decision quality, costs, and revenue protected.
- **Game Controls:** Includes pause/resume, restart, help, and sound controls.
- **Responsive Interface:** Designed to work on desktop and mobile screens.

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

The application runs locally in a web browser without external libraries, APIs, or a backend.

## 🧠 Key Learnings

- Practiced building an interactive application using a single HTML file.
- Explored event-driven programming and state management in JavaScript.
- Learned how to model operational incidents and decision-dependent outcomes.
- Implemented a countdown timer, pause/resume functionality, and game-over conditions.
- Worked with dynamic KPI updates, conditional logic, and performance scoring.
- Explored dashboard design, responsive layouts, and visual feedback.
- Used Claude to accelerate application development and translate a detailed specification into a working prototype.

## 🚀 How to Run

1. Download `day31.html`.
2. Open the file in Chrome, Edge, Firefox, or another modern browser.
3. Click **Start Shift** to begin the three-minute challenge.
4. Resolve incidents, monitor KPIs, and review your final performance report.

## 💡 Reflection

This project demonstrates how an interactive simulation can make complex supply chain decisions easier to explore. It combines dashboard visualization, incident management, and decision-based scoring in a standalone browser application.
