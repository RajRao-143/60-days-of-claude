# Day 31 — AI Supply Chain Control Tower 🚚📦

## 📌 Project Overview

For Day 31 of the **ABTalks 60 Days Claude Challenge**, I built an interactive **AI Supply Chain Control Tower** game using Claude.

The game simulates real-world supply chain disruptions and challenges players to make quick decisions while balancing service levels, customer satisfaction, inventory health, transportation efficiency, operating costs, and protected revenue.

## ✨ Key Features

- **Live KPI Dashboard:** Tracks service level, customer satisfaction, inventory health, transportation efficiency, operating costs, revenue protected, and overall performance score.
- **Dynamic Supply Chain Alerts:** Simulates port congestion, supplier delays, truck breakdowns, stockouts, customs issues, demand spikes, factory failures, weather disruptions, inventory discrepancies, and damaged shipments.
- **Decision-Based Gameplay:** Every action affects relevant KPIs, costs, and business performance.
- **Three-Minute Challenge:** A countdown timer creates time pressure, with alerts arriving more frequently as the round progresses.
- **Live Event Log:** Records incidents, decisions, resolutions, and KPI changes.
- **Final Performance Report:** Displays the final score, grade, alert statistics, decision quality, operating costs, and revenue protected.
- **Game Controls:** Includes pause/resume, restart, help, and sound controls.
- **Responsive Design:** Supports desktop and mobile screens.

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

The application runs locally in a browser without external libraries, APIs, or a backend.

## 🧠 Key Learnings

- Building an interactive application in a single HTML file.
- Managing application state and user interactions with JavaScript.
- Implementing countdown timers and pause/resume functionality.
- Designing decision-based logic with different operational consequences.
- Updating KPIs dynamically and calculating performance scores.
- Creating a responsive dashboard with visual feedback.
- Using Claude to transform a detailed prompt into an interactive application.

## 🚀 How to Run

1. Download `day31.html`.
2. Open it in Chrome, Edge, Firefox, or another modern browser.
3. Click **Start Shift** to begin the three-minute challenge.
4. Respond to incidents, monitor the KPIs, and review the final report.

This project helped me explore how supply chain disruptions and operational decisions can be represented through an interactive simulation. It combines dashboard visualization, incident management, and decision-based scoring in a standalone browser application.
