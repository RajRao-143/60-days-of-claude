# Day 42 — Personal Financial Command Center 💰

## 📌 Project Overview

Built a **Personal Financial Command Center** — a personal finance dashboard designed for Indian college students to track expenses, manage budgets, monitor savings, and make smarter financial decisions.

The application helps students understand their spending habits, plan monthly budgets, and work toward financial goals through an interactive dashboard.

## ✨ Features

- 📊 **Financial Overview** — View income, expenses, savings, and financial health.
- 💸 **Transaction Tracker** — Record and manage daily income and expenses.
- 🎯 **Budget Management** — Set category-wise budgets and monitor spending.
- 🏦 **Savings Goals** — Track progress toward emergency funds, college expenses, and planned purchases.
- 🔮 **What-If Simulator** — Explore how different spending and saving decisions could affect your finances.
- 🧠 **Financial Insights** — Get rule-based insights based on your recorded financial activity.
- 📈 **Financial Health Score** — View an indicative score based on your financial activity.
- 📚 **Investing Basics** — Learn foundational investing concepts before investing real money.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 💾 **Local Data Storage** — Save data in your browser using local storage.
- 📤 **Backup & Import** — Export and restore financial data using JSON.
- 🖨️ **Print Support** — Print a view of your financial dashboard.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open `Personal_Financial_Command_Center.html` in your browser.
3. Explore the dashboard and add your own transactions, budgets, and savings goals.

No backend or external dependencies are required.

## 🎯 Challenge Learnings

- Building an interactive dashboard using HTML, CSS, and JavaScript.
- Implementing client-side data persistence with Local Storage.
- Designing budget tracking and savings goal workflows.
- Creating rule-based financial insights and a what-if simulator.
- Making a responsive, student-focused finance application.

## ⚠️ Disclaimer

This project is for educational and personal budgeting purposes only. Financial health scores and insights are indicative, not professional financial advice. Investing information is educational and does not guarantee returns.
