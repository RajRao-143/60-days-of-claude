How this was built · Prompt design · UX · Extensions

1. The assistant's brain

The system prompt defines role, scope, personalization, realistic planning rules, readiness-score caveats, output format, privacy boundaries, and behavior for incomplete or irrelevant input. Review system_prompt.md included with this project.

Role → Personalization → Plan structure → Safety → Edge cases

2. Why this UI fits

  • Guided profile: collects context that changes career advice without asking for a long essay.
  • Separate tabs: organize plan, milestones, projects, and follow-up chat.
  • Warm palette: cream, forest green, and restrained orange support a calm mentor identity.
  • Clear states: empty, loading, and error messages explain what happens next.

3. API and security

This file asks for an API key when live generation is requested. A key typed into a browser can be exposed; never publish a frontend that uses your personal key. Use a backend proxy that stores credentials securely and applies authentication and rate limits. Direct browser requests may depend on Anthropic API, CORS, account, and model availability. No key is preconfigured or automatically supplied.

4. How to extend it

  • Add a secure backend proxy.
  • Add opt-in accounts, persistence, and user-controlled memory.
  • Add resume/job-description analysis and curated learning-resource tools.
  • Build a flow: explore roles → assess skills → draft plan → review progress → revise.
  • Add automated tests for malformed responses, network failures, rate limits, and missing fields.

5. Readiness score caveat

The score is a provisional coaching estimate based on available evidence, not a scientific measurement or hiring probability. Missing profile evidence should reduce confidence.
