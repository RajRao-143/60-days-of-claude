# LaunchPath AI — Day 57

Day 57 adds a local-first, text-based interview simulator to the existing Day 56 standalone prototype.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Select **Interview simulator**.
4. Choose role, interview type and preset, then start.

No installation, API key, paid service or build step is required.

## Day 57 features
- Quick 5, Standard 10, Deep 15 and Custom (3–20) presets.
- Curated HR and role-tagged technical questions.
- Text answer capture, progress and finish-early support.
- Transparent five-dimension rubric: relevance, structure, correctness, clarity and examples.
- Evidence-linked answer review, one strength, one improvement and a practice action.
- Recent session history stored in browser localStorage.
- Existing roadmap, resource library, tutor, aptitude and coding practice retained.

## Important limitations
- Evaluation is a transparent heuristic practice indicator, not expert/human grading and not a hiring prediction. It uses answer length, keyword coverage and structural cues; it cannot reliably establish factual correctness.
- No personality, accent, emotion or protected-trait assessment is performed.
- Voice mode is not enabled; text mode is the reliable fallback.
- Data is local to this browser and does not sync between devices.
- The app does not call an external AI service.
