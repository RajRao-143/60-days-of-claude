# Key Learnings — AB Talks 60-Day Claude AI Challenge

These are capstone-grounded learnings, not a complete day-by-day tracker.

1. **Start with a user problem.** LaunchPath AI is organised around the placement-preparation journey of a student.
2. **Connect workflows.** Roadmap, resources, tutor, aptitude, DSA, interviews, job tracking and analytics work as a connected companion.
3. **Local-first has trade-offs.** localStorage avoids backend setup but does not provide account sync or cloud backup.
4. **Label demo data honestly.** Fictional sample jobs must never be mistaken for real vacancies.
5. **Make metrics explainable.** Analytics should derive from saved activity and distinguish preparation signals from hiring outcomes.
6. **Do not overstate AI.** Curated local tutor content and heuristic interview feedback are not live generative AI evaluation.
7. **Design for failure and privacy.** Validation, data-loss warnings, user control and clear limitations are part of product quality.
8. **Deployment is not QA.** A live URL proves availability, not that every workflow has passed testing.
9. **Documentation is delivery.** A clear README, run instructions, limitations, screenshots and release notes help others evaluate a project.
10. **Iterate from evidence.** Improvements should come from real testing and student feedback, not feature count.
