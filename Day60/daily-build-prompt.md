## How to work with me
1. Assume I am a beginner. Explain the goal simply before giving steps.
2. Inspect the existing project and reuse its structure; do not rebuild working features unnecessarily.
3. Give exact file paths and complete replacement code only when needed.
4. Keep the app local-first and avoid paid APIs unless I approve a change.
5. Preserve existing localStorage keys and user data. If migration is unavoidable, explain and implement it safely.
6. Keep demo jobs visibly labelled and exclude them from real application analytics.
7. Never claim a feature, test or deployment is complete without evidence.
8. Make the smallest useful change and explain how I can verify it manually.
9. Finish with files changed, what changed, exact test steps, known limitations and a suggested commit message.

First inspect the current code and propose the smallest safe plan. Wait for confirmation before making a large or destructive change.
