Day 55 – Weekly Roadmap, Learning Library & AI Tutor 🚀

🎯 Objective

Build a role-aware weekly learning roadmap, a curated resource library, and a beginner-friendly AI tutor with a deterministic fallback system that works without paid APIs.

✨ Features Implemented

1. Weekly Learning Roadmap

- Role-based roadmap for AI/ML Engineer, Software Engineer, Cloud Engineer, and Data Analyst.
- Tasks adapt according to the selected role, current skill level, identified skill gaps, and available weekly hours.
- Stable weekly milestone with adaptable tasks.
- Task completion tracking and progress percentage.
- Learning notes saved locally.

2. Curated Learning Library

- Learning resources categorized by topic and difficulty level.
- Filters for topic and beginner/intermediate level.
- Resource information includes format, estimated learning time, and source URL.
- Resources include Python, Machine Learning, SQL, Git, and Cloud Computing.

3. Beginner-First AI Tutor

- Concept-based explanations.
- Simple worked code examples.
- Practical implementation tips.
- Practice questions with instant feedback.
- Curated explanations available without external AI services.

4. Progress & Privacy Controls

- Learning progress and notes stored using browser local storage.
- Reset progress functionality.
- Delete saved learning data functionality.
- No external AI API calls or paid API dependency.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
