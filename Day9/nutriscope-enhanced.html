Nutrition sources

Where the estimates in NutriScope are grounded, and how to read them.

USDA FoodData Central

The primary reference database for food composition values used to approximate macro and micronutrient content per 100g.

NIH Office of Dietary Supplements

Reference intake values (RDAs) for vitamins and minerals such as iron, calcium, vitamin D and B12 used for target calculations.

WHO nutrition guidance

General guidance on energy balance, macronutrient distribution ranges, and healthy dietary patterns.

About the data

NutriScope's 66-food library, calorie targets, and nutrient RDAs are approximate educational estimates built from typical public reference values. Actual nutrient content varies by brand, preparation method, ripeness and portion size. NutriScope does not connect to any external database or API — every figure is bundled directly into this application so it can run fully offline.

Educational disclaimer

NutriScope is for educational purposes only. Nutrition estimates are approximate and are not medical advice. Speak with a doctor or registered dietitian before making significant dietary changes.
