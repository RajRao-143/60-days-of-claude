# LaunchPath AI — Day 58: Jobs & Calendar

## Run locally
1. Extract the Day58 folder or ZIP.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. Select **Jobs & calendar**.
4. The sample records are visibly labelled as fictional demo data. Add a real opportunity using the form.

No package installation, API key, paid API, backend or build command is required. This is a standalone local-first HTML prototype.

## Day 8 scope delivered
- Manual job creation, editing and deletion.
- Required job title, company, location, role, source and last-checked date.
- The seven workbook statuses: Saved, Applied, Assessment, Interview, Offer, Rejected, Withdrawn.
- Application date, deadline, notes and next action.
- Status summary, search and status filter.
- Date-ordered calendar/agenda and in-app deadline reminders.
- Fictional sample listings are clearly labelled; no live job feed is claimed.
- Job records are stored in this browser using localStorage.

## Data and limitations
- Data stays in the current browser profile and does not sync across devices.
- Clearing browser site data can remove records. There is no cloud backup or account sync.
- In-app reminders appear when the app is opened; there are no SMS, WhatsApp or browser push notifications.
- Demo jobs are fictional and are not vacancies. Verify real opportunities at their original source before applying.
- This is not integrated into a separate framework/backend repository and has not been deployed by this package.
