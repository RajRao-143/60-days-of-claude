Day 58 — Job Discovery, Application Tracker & Calendar

Overview

As part of the ABTalks 60-Day Claude AI Challenge, Day 58 focuses on extending LaunchPath AI — Your Intelligent Placement Readiness Companion with a job discovery and application management module.

The goal is to help students organize job opportunities, track application progress, and stay aware of upcoming deadlines.

Features Implemented

1. Job Discovery

- Job cards with title, company, location and role.
- Source and last-checked date for each listing.
- Clearly labelled demo listings.
- Manual job entry as the primary fallback.

2. Application Tracker

Supports seven application statuses:

- Saved
- Applied
- Assessment
- Interview
- Offer
- Rejected
- Withdrawn

Users can:

- Add new job applications.
- Edit existing job details.
- Update application statuses.
- Add application dates and deadlines.
- Maintain notes and next actions.
- Delete application records.

3. Calendar & Reminders

- Date-based application agenda.
- Upcoming deadline visibility.
- Overdue application reminders.
- In-app reminders without SMS or WhatsApp integration.

4. Data Persistence

- Uses browser Local Storage.
- Application records remain available after refreshing the page in the same browser.
- No external database or paid API dependency.

Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

Important Limitations

- Job listings are demo data, not a verified live job feed.
- Manual job entry is supported.
- Data is stored locally in the browser and is not synchronized across devices.
- Reminders are in-app only; background notifications are not guaranteed.

Outcome

Day 58 extends LaunchPath AI with a practical job application workflow, helping students manage opportunities, monitor application progress and keep track of important deadlines.
