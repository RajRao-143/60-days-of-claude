# Day 33 — Media Integrity Analyzer 📰

**ABTalks 60 Days Claude Challenge**

## Overview

Media Integrity Analyzer is an interactive, offline web application built with Claude. It helps users identify misleading headlines, compare claims with article evidence, and develop critical media literacy.

## Features

- Headline Detective
- Misleading phrase highlighting
- Headline accuracy scoring
- Evidence-based explanations
- Fair headline rewrites
- Live integrity metrics
- Final results dashboard
- Offline functionality using HTML, CSS, and JavaScript
