# Day 33 — Media Integrity Analyzer 📰

**ABTalks 60 Days Claude Challenge**

## 📌 Overview

Media Integrity Analyzer is an interactive, offline web application built with Claude to help users critically evaluate headlines and understand how media framing can influence perception.

The project encourages critical thinking, evidence-based analysis, and responsible media consumption through an engaging, guided experience.

## ✨ Features

- **Headline Detective:** Analyze fictional headlines against their corresponding articles.
- **Misleading Phrase Detection:** Identify highlighted claims that may distort the article's actual meaning.
- **Accuracy Scoring:** Evaluate headline accuracy using weighted claims and supporting evidence.
- **Fair Headline Rewrites:** Compare misleading headlines with more accurate alternatives.
- **Live Metrics:** Track headline accuracy and other relevant integrity indicators.
- **Final Dashboard:** Review results, key takeaways, and practical habits for evaluating media.
- **Replay Experience:** Explore new scenarios and practice critical reading.
- **Offline Functionality:** Runs directly in a browser without external APIs or libraries.
- **Responsive Interface:** A polished Claude Orange-inspired theme with interactive elements.

## 🎯 Learning Outcomes

Through this project, I explored how to:

- Compare headlines with supporting article evidence.
- Recognize misleading framing and exaggerated claims.
- Evaluate information before accepting or sharing it.
- Use interactive feedback to support guided learning.
- Build a standalone, responsive web application using Claude.

## 🚀 How to Run

1. Download `day33.html`.
2. Open the file directly in a modern web browser.
3. Explore the scenarios and complete the analysis.
4. Review the metrics and final dashboard.

No installation or internet connection is required after downloading the file.

## 💡 Key Takeaway

A headline can attract attention without accurately representing the full story. Reading beyond the headline, checking supporting evidence, and questioning emotional framing are essential habits for becoming a more informed digital citizen.
