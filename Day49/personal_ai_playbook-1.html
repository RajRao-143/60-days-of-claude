Learning Guide

Learn to design reliable workflows, not just collect prompts.

Prompt design

Role sets perspective; objective defines result; context reduces guesswork; constraints set boundaries; format shapes the answer. Use examples and quality checks when consistency matters.

Specific context beats a long, vague instruction.

Controlled iteration

A useful loop needs a goal, criteria, improvement strategy, stop condition and safety rules. Without them, revisions can drift.

Always define when the AI should stop and ask you.

ChatGPT + Claude

Use ChatGPT as daily tutor, planner and reviewer. Use Claude for substantial implementation and long context. Capabilities change, so verify important outputs.

Confident output is not verified output.

Verification & privacy

Run code, inspect diffs, test edge cases and understand changes before shipping. Never paste passwords, API keys or private credentials into prompts.

AI proposes. You verify and own the result.

Keyboard shortcuts

Ctrl + K focuses workflow search · Ctrl + Enter copies the current prompt in either builder · Esc closes the help panel.

Backup

Saved workflows live in browser localStorage. Clearing browser data can remove them. Export JSON regularly to back up or move them.
