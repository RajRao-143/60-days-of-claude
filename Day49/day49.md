🧠 Personal AI Playbook

A personalized AI productivity workspace designed to make everyday AI usage more structured, consistent, and effective.

📸 Dashboard Preview

"Personal AI Playbook Dashboard" (personal_ai_playbook_dashboard.png)

🚀 Overview

The Personal AI Playbook is a single-file interactive HTML application that helps organize AI workflows, build better prompts, and create repeatable AI-assisted processes.

It is designed around a simple workflow:

Plan → Build → Review → Improve

✨ Features

- Dashboard: Central workspace to access AI tools and workflows.
- AI Workflows: Ready-to-use workflows for coding, DSA, projects, academics, research, and career development.
- Prompt Builder: Create structured prompts using modular prompt components.
- Loop Builder: Design iterative workflows with evaluation criteria and improvement steps.
- Saved Workflows: Save, edit, duplicate, favorite, and search workflows.
- Import & Export: Manage saved workflows through JSON files.
- Responsive Design: Works across different screen sizes.
- Dark Mode: Switch between light and dark themes.

🛠️ Tech Stack

- CSS
- JavaScript
- LocalStorage

💡 Purpose

The goal is to move beyond random AI prompting and build a structured system for using AI in:

- Problem solving and debugging
- DSA practice
- AI/ML project development
- Academic preparation
- Research and documentation
- Career planning and internship preparation

▶️ How to Run

1. Clone or download this repository.
2. Open "personal_ai_playbook.html" in any modern web browser.
3. Start exploring the workflows and prompt-building tools.

No installation or backend setup is required.
