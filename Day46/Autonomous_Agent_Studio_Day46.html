03 / Agent responsibilities

Planner

Breaks the objective into milestones, dependencies, and acceptance checks.

Executor

Produces the first substantive project draft and implementation plan.

Evaluator

Scores the current draft against the supplied rubric with evidence.

Critic

Finds gaps, risks, unsupported claims, and high-impact weaknesses.

Improver

Uses the previous evaluation and critique to revise the draft.

Memory Manager

Compresses durable decisions and unresolved items between rounds.

Safety Monitor

Flags unsafe instructions, secrets, fabricated execution, and data risks.

Final Reviewer

Checks the final deliverable after the stop condition fires.
