Research methodology and data collection

Research snapshot and scope

Snapshot date: 03 November 2026. The comparison covers the consumer-facing products Claude, ChatGPT, Gemini, and Perplexity for student and developer workflows. It is not a comparison of every underlying model, API, enterprise contract, or third-party integration.

Source hierarchy

Official provider documentation is the primary authority for plan descriptions, feature availability, subscription pricing, and model context specifications. Independent benchmark sources are used only to illustrate specific measured tasks under stated configurations.

Scoring methodology

Each criterion receives a 0–10 evidence-based analyst assessment. Scores summarize product capability and suitability for the stated audience, considering documented features, workflow coverage, accessibility, and known limitations. They are not standardized benchmark results or user satisfaction statistics.

Evidence labels:

  • Verified benchmark result: A named, reproducible benchmark result with an identified model and evaluation setup.
  • Evidence-based analyst assessment: A reasoned comparative judgment based on documented product capabilities.
  • Estimate: An explicitly approximate figure.
  • Data unavailable: Insufficient comparable evidence to assign a defensible score.

Weighted score formula

Weighted Score = Σ(score × selected weight) / Σ(selected weights).

Scores with unavailable data are omitted from both numerator and denominator for that platform. If all weights are zero, the system uses equal weights of one for all criteria.

How to interpret rankings

A difference of a few tenths is not proof of a meaningful real-world performance advantage. Scores are analyst judgments represented numerically to support transparent prioritization. Change the weights, inspect the evidence, and test the products on your own tasks before choosing.

Limitations and missing information

  • There is no single controlled benchmark evaluating all four complete consumer assistants across all six criteria.
  • Model quality can change independently of the app, plan, routing policy, or available tools.
  • Free-tier quotas and message limits are dynamic and are not directly comparable across providers.
  • Context-window specifications differ by model, plan, interface, and task. An API model limit does not automatically equal the consumer application's usable context.
  • Speed depends on model selection, server load, task complexity, region, and network conditions. No comparable speed score is asserted.
  • Citation presence does not guarantee source correctness, completeness, or faithful interpretation.
  • Prices are not Indian checkout quotes. Local taxes, exchange rates, and regional plan variations may apply.

Conflicts and resolution

When official pages and third-party summaries disagree, the official provider page takes precedence for its own plan and feature facts. Benchmark results are retained only with their exact benchmark identity and evaluation configuration. Results from different harnesses, models, or dates are not averaged.

Important uncertainty

This is a static research dataset embedded in the HTML. The application does not fetch live data, claim live verification, or require an API key. Source links lead to external pages that may change after this snapshot.

Scoring definitions and evidence labels

ANALYST A comparative judgment grounded in documented features and workflow suitability.

VERIFIED BENCHMARK A score reported by a named benchmark under a documented evaluation setup.

ESTIMATE A clearly identified approximation.

DATA UNAVAILABLE There is not enough comparable evidence to assign a defensible score.

Practical recommendation for students and developers

Do not subscribe based on one aggregate number alone. Give each assistant the same representative tasks: explain a difficult concept, debug a real code issue, research a topic using primary sources, and produce a structured deliverable.

For coding, test the same repository issue and inspect whether the suggested fix passes tests. For research, open citations and verify the supporting passage. For learning, check whether explanations adapt to your level and help you solve a problem independently.
